# 安装与配置

> 目标：10 分钟内让 `doctor.py` 全绿。遇到问题先看文末「故障排查」。

## 一、前置条件

| 组件 | 版本 / 说明 | 必需性 |
|---|---|---|
| Windows | 10 / 11 x64（PowerShell 5.1+） | 必需（采集侧） |
| Python | 3.11+（推荐 3.12） | 必需 |
| Chromium | 任意 120+ 版本，供 patchright 驱动 | 采集类必需 |
| patchright | 反检测 Playwright（`pip install patchright`） | 采集类必需 |
| ffmpeg | 完整版（支持 wav / m4a） | ASR / 录屏/封面必需 |
| faster-whisper | 本地 ASR（可选 GPU / CUDA） | 抖音、无字幕 B 站必需 |
| 飞书机器人 | 自定义机器人 Webhook 或自建应用 | 可选（通知/日报） |

两种装法：

- **项目自带运行时**（推荐）：把 Python、Chromium、ffmpeg、ASR 模型放在数据根 `runtime/`，脚本会自动找到；
- **系统环境**：用系统 Python + `pip install -r requirements.txt`，并自行把 Chromium 加入 `PATH`。

## 二、安装

```powershell
# 1) 获取代码（克隆或解压压缩包到任意目录）
git clone https://github.com/<GITHUB_USER>/AutoMedia.git D:\work\AutoMedia

# 2) 先干跑，确认它要做什么
cd D:\work\AutoMedia
powershell -NoProfile -ExecutionPolicy Bypass -File scripts\install.ps1 -DryRun

# 3) 正式安装（创建 data/ 1AMdata/ 1信息源/，检查运行时）
powershell -NoProfile -ExecutionPolicy Bypass -File scripts\install.ps1

# 可选：安装 Python 依赖 / 把四个 skill 链接到 DSH 工作区
powershell -File scripts\install.ps1 -InstallDeps
powershell -File scripts\install.ps1 -ProjectRoot D:\你的DSH工作区

# 4) 自检
python scripts\doctor.py          # 表格
python scripts\doctor.py --json   # 机器可读
```

## 三、目录与数据根

`install.ps1` 会在**数据根**创建：

```
<数据根>/
  data/            登录态与密钥（git 忽略）
    sau/cookies/   B站 cookie JSON
    social/        抖音浏览器 profile
    accounts/      小红书 profile
    secrets/       feishu.env 等
  1AMdata/         采集 / 蒸馏产出
  1信息源/         资讯素材库（<日期>/事件素材）
  runtime/         可选的 Python / Chromium / ffmpeg / ASR 模型
```

**数据根默认 = 仓库根目录**。想放到别处（例如磁盘空间更大的盘）：

```powershell
$env:AUTOMEDIA_ROOT = "D:\media-data"   # 之后所有脚本都写这里
```

| `CREATOR_RUNTIME` | `<数据根>/runtime` | creator-distill 运行时 |

## 六、登录细节

### B站（cookie JSON）

首选数据真源：`data/sau/cookies/bilibili_*.json`，结构为 biliup 导出的
`{"cookie_info": {"cookies": [{"name": "SESSDATA", "value": "..."}, ...]}}`。
也支持 `credentials/bili_cookie.txt`（一行完整 cookie 字符串，或两行格式）。

读取优先级：`BILI_COOKIE` 环境变量 → `--cred-file` → JSON 真源 → `credentials/bili_cookie.txt`。
`preflight()` 会检查 `nav.isLogin`，失效直接 `exit=3`，不会空跑。

### 抖音（浏览器 profile）

```powershell
python douyin-auto\scripts\douyin_login.py --profile data\social\douyin-verify-profile --timeout 600
```

会打开**可见**浏览器，扫码登录后 profile 留在本地。注意：

- 必须 headful（无头会被识别）；
- 不同账号用不同 profile，且**不能并发**（Chromium 锁 + 风控翻倍）；
- 验证码出现时脚本会停下保留进度，人工过一次再继续。

### 小红书（浏览器 profile）

用专用 profile 打开小红书网页扫码，登录态保存在
`data/accounts/xiaohongshu/profile/`。creator-distill 与采集器共用这个 profile。

## 七、定时任务

```powershell
# 注册 B站监听任务（Inbox / S / A / B / 关键词 / 日报，08:00 起错峰）
powershell -File bilibili-auto\scripts\register_watch_tasks.ps1

不想用计划任务，可用常驻循环：`bilibili-auto\scripts\run_bili_continuous.ps1`。

## 八、故障排查

| 现象 | 原因 / 处理 |
|---|---|
| `playwright` 报 Chromium 不存在 | 把 Chromium 放到 `<数据根>/runtime/browsers/chromium-*/chrome-win64/chrome.exe`，或 `patchright install chromium` |
| `Target page, context or browser has been closed` | 同一 profile 被另一个进程占用；确认没有并发的采集实例 |
| B站 `exit=3` / `[NO-LOGIN]` | cookie 过期；重新扫码导出，别开第二套登录通道 |
| B站 `-352` | 缺 `dm_img_*` 反爬参数；用仓库内脚本（已内置），或过一会儿再试 |
| 抖音出现验证码 | 立即停止；浏览器过一次验证码，降低频率后继续（脚本保留进度） |
| ASR 报 CUDA 显存不足 | 换 `--asr-model small`，或减少并发 / 关闭其他 GPU 程序 |
| 中文文件名写文件失败 | 标题以 `.` / 空格结尾的 Windows 问题；脚本 `safe_name()` 已处理，旧目录需手工改名 |
| 中文乱码 | PowerShell 5.1 用 GBK 解析 UTF-8 脚本；仓库脚本已按 BOM 处理，自己改脚本时用 UTF-8 BOM |
| 执行策略禁止脚本 | `powershell -NoProfile -ExecutionPolicy Bypass -File ...` |
| 飞书 403 / 校验失败 | 检查 webhook 是否过期、签名密钥是否填对、机器人是否在群里 |

## 九、清理

# 只清缓存（安全）
Remove-Item -Recurse -Force .cache, */__pycache__, */logs -ErrorAction SilentlyContinue

Remove-Item -Recurse -Force data, 1AMdata, 1信息源
```

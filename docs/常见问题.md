# 常见问题

## 1. 会不会被封号？

只读 + 限流 + 断点续传可以显著降低风险，但**没有任何项目能保证不封**。
最坏情况按平台差异：

| 平台 | 风控 | 建议 |
|---|---|---|
| B站 | 中等 | 单并发、间隔 ≥1.5s、搜索类 2.5s、23:00–08:00 静默 |
| 抖音 | **高**（限流→禁言→封号→设备封禁） | 独立小号 + 独立 profile、headful、首次人工值守 |
| 小红书 | 中 | 独立 profile、日限量、出现验证码即停 |

如果账号很重要，不要用它跑采集。

## 2. 一定要装 DSH 吗？

不需要。四个 Skill 本质是 Python 脚本，`python xxx.py --help` 就能用。
DSH 只是让你可以用自然语言调度它们（读 `AGENTS.md` 自动安装/调用）。

## 3. 数据存在哪？会上传吗？

全部在本机数据根：`1AMdata/`（采集/蒸馏）、`1信息源/`（资讯素材）、`data/`（登录态与密钥）。
不会上传任何数据；飞书推送只发到你配置的群。

## 4. 需要多大磁盘？

| 内容 | 粗略体积 |
|---|---|
| 代码 | < 5 MB |
| 运行时（Python + Chromium + 模型） | 5–7 GB |
| B站 826 个 UP 的元数据 + 字幕 | 20–40 GB |
| 抖音 250 个博主视频（不存视频） | 3–5 GB |
| 资讯素材（含截图/录屏） | 0.1–0.5 GB / 天 |

## 5. 换电脑怎么迁移？

拷三样：`data/`（登录态）、`1AMdata/`（数据）、`1信息源/`（素材）。
新机器重跑 `install.ps1` 与 `doctor.py`；登录态过期就重新扫码。

## 6. 可以只要其中一个 Skill 吗？

可以。四个目录互相独立，只复制你需要的那一个，并保持数据根里有对应的 `data/` 与 `1AMdata/` 即可。

## 7. 支持 macOS / Linux 吗？

`news-source`、`creator-distill` 的分析部分与平台无关；采集侧的浏览器自动化、PowerShell 脚本、
计划任务按 Windows 编写。移植主要成本在路径层与进程管理。

## 8. 为什么产出是「落盘 + 少进对话」？

一次采集可能产生几万字文本。项目设计成**全部写盘、屏幕只打印摘要**，
所以单次采集的对话成本约 2–5k token，与采 10 条还是 30 条无关。

## 9. 采集内容可以商用吗？

采集仅用于个人研究与创作参考。二次发布请获得授权、标注来源，并遵守平台条款与当地法律；
AI 生成画面需加「AI 生成」标识。

## 10. 飞书一定要配置吗？

不是。不配也能用，只是没有日报/异常推送。配置见 `python scripts\feishu_setup.py`（两种模式：自定义机器人 / 自建应用）。

## 11. 如何更新？

```powershell
cd AutoMedia
git pull
python scripts\doctor.py
```

代码在仓库、数据在 `data/`/`1AMdata/`，互不覆盖；如有配置变更会写在 CHANGELOG。

## 12. 项目的 Roadmap / 怎么参与？

见 README 的 Roadmap 与贡献章节。Issue / PR 都欢迎：新平台 adapter、新的蒸馏维度、稳定性修复、文档改进。

# OpenAI 商业化加速：ChatGPT 商家资料 + 收购 Odessia 做旅行 Agent

> 事件目录：`1信息源/261111/06_openai-business/` ｜ 抓取时间：2026-11-11 ｜ 原文 3 篇 / 链接 4 个

## 一、事件摘要

- OpenAI 推出「Businesses in ChatGPT」：商家可以认领/创建资料，ChatGPT 内直接展示商家信息，并面向美国电商企业提供 AI Agent 投放能力。
- TechCrunch 评价：这让 ChatGPT 更像 Google——从「回答问题」转向「发现+交易」。
- OpenAI 还收购了 AI 旅行智能体公司 Odessia，创始人 Francis Davidson 加入，探索旅游方向的 Agent。

## 二、时间线

- 11-10：OpenAI 发布 Businesses in ChatGPT

- 11-11：IT之家报道收购 Odessia

## 三、关键数字

- 入口：ChatGPT 内商家资料
- 市场：先面向美国电商企业
- 收购：Odessia（AI 旅行智能体）

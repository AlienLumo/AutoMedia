# 阿里三线并进：Qwen4 预告、Qwen Code 1.0 开源、平头哥赴港 IPO

> 事件目录：`1信息源/261111/05_alibaba-qwen-tpu/` ｜ 抓取时间：2026-11-11 ｜ 原文 3 篇 / 链接 3 个

## 一、事件摘要

- 阿里官宣新一代千问大模型 Qwen4 即将发布（知识理解、世界感知、Coding 与 Agentic 能力进阶），预览版已首发上线。
- Qwen Code 1.0 发布：Qoder 与 Qwen Code 融合开源，Harness 统一衔接模型、工具与执行过程。
- 芯片子公司平头哥（T-Head）拟赴港交所 IPO，已于 9 月 11 日保密递表；CNBC 称其为「英伟达的挑战者」。

## 二、时间线

- 09-11：平头哥保密递表港交所
- 11-11：阿里官宣 Qwen4 预告与 Qwen Code 1.0
- 11-11：CNBC 报道平头哥 IPO 计划

## 三、关键数字

- 平头哥：已保密递表
- 阿里港股：当日跌约 1%，年内跌约 29%
- Qwen Code：1.0 版本

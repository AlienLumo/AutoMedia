# AI 市场回调：OpenAI/Anthropic 估值回落，基金以史上最快速度抛售科技股

> 事件目录：`1信息源/261111/08_ai-market-rout/` ｜ 抓取时间：2026-11-11 ｜ 原文 2 篇 / 链接 3 个

## 一、事件摘要

- Bloomberg 报道：随着 AI 市场回调冲击融资，OpenAI 与 Anthropic 的估值出现回落；对冲基金正以史上最快的速度之一抛售全球科技股。
- 但二级市场分化明显：费城半导体指数涨 2.67%，博通、AMD、应用材料涨超 6%，而英伟达逆势跌 5.89%。
- 一边是一级市场估值降温，一边是芯片股反弹——资本正在从「讲故事」转向「看兑现」。

## 二、时间线

- 11-09：Bloomberg 报道估值回落与抛售
- 11-10：对冲基金抛售、芯片股分化
- 11-11：中文媒体跟进

## 三、关键数字

- 费半：+2.67%
- 博通 +6.25% / AMD +6.12% / 应用材料 +6.94%
- 英伟达：-5.89%

- Anthropic 发布 Claude Fable 5.2 与 Claude Mythos 5.2：编码、推理、科研、网络安全、机器人能力显著提升，输出速度最高 +30%、成本 -20%。
- 定价：每百万 Token 输入 8 美元、输出 40 美元（Fable 5.1 为 10/50 美元），是「能力更强、价格更便宜」的组合拳。

# 视觉素材使用指南（2026-11-11 素材库）

> 本库除了文字稿，还为每个事件收集了**可直接用于视频的视觉素材**：整页长图、标题区截图、滚动分镜、页面大图、页面滚动录屏，以及 5 位关键人物头像。

## 一、素材类型与命名

```
<事件>/
  截图/
    CN_<来源>_整页.png      整页长图（最长，适合做"证据感"）
    CN_<来源>_标题.png      标题区特写（适合开场钩子/标题卡）
    CN_<来源>_滚动1..4.png  滚动分镜（0%/33%/66%/90% 处，适合做 B-roll 定格）
    CN_<来源>_图片1..5.jpg  页面大图（人物/图表/产品图）
  录屏/
    CN_<来源>_滚动.mp4      页面滚动视频（约 4.5 秒，1080 宽，哑音）
  关键人物/
    <姓名>_<英文名>.jpg      Wikipedia/Wikimedia 头像（附来源 txt）
```

- `CN_` = 中文页面，`EN_` = 英文页面，`OFFICIAL_` = 官方动态页。
- 录屏是 **1080 宽、8fps、约 4.5 秒**的滚动，可直接放慢 0.5x 当 B-roll，也可以裁成竖屏。

## 二、在 60 秒短视频里怎么用（3-5-3 框架）

| 视频段落 | 用哪类素材 |
|---|---|
| 开场 3 秒钩子 | `*_标题.png`（大字标题特写）或 `关键人物/*.jpg` |
| 事实层 | `*_整页.png` 局部裁切 + `*_滚动1..4.png` 逐张快切 |
| 数据层 | 从 `*_整页.png` 裁出数字/表格区域；或 `*_图片*.jpg` |
| 观点/判断层 | 纯色底 + 大字（不需要素材），或人物头像 + 引语 |
| 结尾 CTA | 录制素材的最后一帧 + 台标 |

## 三、版权与引用规范（重要）

1. **截图必须标注来源**：画面角落打 `来源：<媒体名> · 2026-11-11`，与 `links.json` 一致。
2. **人物头像**：来自 Wikimedia Commons，多为 CC BY-SA；按各自 `_来源.txt` 里的链接与授权要求署名。
3. **付费墙页面**（Bloomberg/NYT/MarketWatch/Investing）**没有取到正文，也没有截正文**；只有标题/摘要级信息，不要伪造截图。
4. 截图里若出现用户头像、昵称、余额等隐私信息，发布前打码。
5. AI 生成的画面/配音需按平台要求加「AI 生成」标识。

## 五、如何更新/重抓

```powershell
cd <项目根>/news-source/scripts
<项目根>/runtime/python/python.exe capture_visuals.py                 # 全部重抓
<项目根>/runtime/python/python.exe capture_visuals.py --only 01_anthropic-ipo
<项目根>/runtime/python/python.exe capture_visuals.py --people        # 只抓关键人物
```

依赖：项目内 chromium（`runtime/browsers/chromium-1208`）+ patchright（`runtime/python`）+ imageio_ffmpeg 的 ffmpeg。

# 苹果限制 Apple Intelligence 云端额度：AI 算力开始「按量收费」

> 事件目录：`1信息源/261111/10_apple-ai-quota/` ｜ 抓取时间：2026-11-11 ｜ 原文 1 篇 / 链接 1 个

## 一、事件摘要

- 苹果支持文档显示：部分依赖服务器端模型的 Apple Intelligence 功能将受使用限制，涉及 Siri AI、图乐园、照片智能编辑，以及快捷指令中的 AFM 3 Cloud / AFM 3 Cloud Pro。
- 用户可通过订阅 iCloud+ 扩容；Logic Pro 已单独售卖用量包。
- 这意味着：连苹果也开始把「云端 AI 算力」当成需要计价的资源。

## 二、时间线

- 11-11：苹果支持文档与媒体报道

## 三、关键数字

- 受限功能：Siri AI / 图乐园 / 照片智能编辑 / 快捷指令云端模型
- 扩容方式：iCloud+ 订阅
- 另售：Logic Pro 用量包

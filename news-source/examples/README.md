# examples · 2026-11-11 示例素材库

本目录是 `news-source` 的一次真实产出示例（日期目录 `261111` = 2026-11-11），用于说明
「资讯池聚类 → 抓原文 → 生成事件文档/口播稿 → 抓视觉素材」这条流水线最终会产出什么：

```
261111/
  README.md               当日素材库索引（事件 / 原文 / 链接 / 截图 / 录屏 / 抓取缺口）
  _index.json             抓取状态索引
  _visual_manifest.json   视觉素材清单（截图 / 录屏文件名）
  视觉素材使用指南.md      素材类型、60 秒用法、版权与引用规范
  <事件>/
    README.md             事件摘要 + 时间线 + 关键数字 + 素材清单 + 视觉素材
    文案素材.md            60 秒口播草稿 + 3 分钟结构 + 钩子/标题/金句/数据/观点/风险
    links.json            链接与抓取状态（status / chars / 本地文件名）
  关键人物/                人物头像清单与来源说明（仅清单，不含头像图片）
  渲染输出/                成片渲染的文本元数据（说明 / 配置 / 验收 JSON）
```

## 收录范围（重要）

本目录**只收录文本与链接**：

- 收录：`*.md`、`*.json`。
- 不收录：`raw/`（原始 HTML）、`原文/`（抓取清洗后的正文全文）、`截图/`、`录屏/`、
  `_render/`（渲染脚本与缓存）、`cache/`，以及所有图片 / 视频 / 音频文件。

因此 `links.json` 里的 `file` 字段（如 `原文/ithome-ipo.md`）指向的正文文件不在本仓库；
`_visual_manifest.json`、`关键人物/README.md`、`渲染输出/` 中提到的截图 / 录屏 / 头像 / 成片文件同样不在本仓库。
这些属于数据产物与第三方版权内容，按 `SKILL.md` 的边界要求不入库，需要在本机按流程重新抓取/渲染生成。

## 链接全部保留

示例中的信息源链接、原文链接、事件链接均原样保留，未做任何脱敏或隐藏：

- 事件原文链接：各 `<事件>/links.json`、`<事件>/README.md`
- 当日选题与链接：`../config/events/261111.json`
- 上游信息源注册表：`../config/sources.tsv`（281 个源，含 `url` / `feed` 两列）

付费墙 / 反爬页（Bloomberg、NYT、MarketWatch、Investing 等）只有标题/摘要级信息，
会明确标注在 `README.md` 的「抓取缺口」里，不编造正文。
